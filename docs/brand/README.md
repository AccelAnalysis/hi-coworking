# Hi Coworking Brand

This directory contains the canonical public-facing design and brand authority for Hi Coworking.

- [Hi Coworking Design & Brand Guide](./HI_COWORKING_DESIGN_BRAND_GUIDE.md)

The guide applies to the public website, booking, events, bookstore, community, member-entry surfaces, campaigns, social creative, print collateral, and environmental graphics. Staff and administrative tools should retain the core identity while using denser patterns only where the work genuinely requires them.

Public-facing work must feel like a welcoming neighborhood workspace and hospitality brand—not a software dashboard. New or revised interfaces should be reviewed against the acceptance checklist in the guide before merge.
