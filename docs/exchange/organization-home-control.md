# Organization home control

Organization home is a persistent workspace-level control whenever an Actor organization is validated.

It uses the server-returned preferred establishment, then headquarters, primary, and another active coordinate. It sets Subject to Actor, Secondary Subject to the establishment, opens the drawer, applies the activation camera, and leaves all authority checks server-side.

The control and dimension group share the responsive map-control layer. Desktop offsets avoid the right drawer; mobile uses a bottom drawer so both controls remain visible and hit-testable.
