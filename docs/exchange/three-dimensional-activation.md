# Three-dimensional activation

The establishment activation preset is zoom 16.5, pitch 55°, and bearing -20°. It selects the establishment, opens the organization drawer, enables the supported 3D-building layer, and renders the selected point through a dedicated unclustered source.

The selected marker radius is 16px with a 6px white selection ring, approximately 1.6× the ordinary 10px context point. Desktop drawer padding is 440px on the right; compact layouts use a bottom sheet and reserve 48% of viewport height. Reduced-motion preferences set camera transition duration to zero.

The workspace-level control can still return to 2D pitch/bearing zero and restore the standard 3D values.
