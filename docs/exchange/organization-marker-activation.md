# Organization marker activation

Marker activation has two server-derived axes:

- Private actor: exact-active member, active physical establishment, and confirmed valid coordinate.
- Public: approved directory organization, active non-home/non-virtual/non-mailing establishment, confirmed coordinate, and explicit coordinate publication.

The establishment save response returns private and public marker states. Private actor availability does not require directory publication or an opportunity. Public and private versions deduplicate by location ID in the map workspace.

Resolvable states point back to Organization Profile or Establishments. The activation link selects the exact establishment and opens the organization drawer at zoom 16.5, pitch 55, and bearing -20.
