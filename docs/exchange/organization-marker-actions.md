# Organization marker actions

Selecting an establishment keeps Actor unchanged, sets the parent organization as Subject, sets the establishment as Secondary Subject, and opens the organization drawer. Those values persist through Opportunities, Referrals, Intelligence, and Resources.

External actions are server-allowlisted and include public profile/website, save, contact, introduction, referral routing, resources, capabilities, and organization-issued opportunities. Contact/introduction responses never disclose protected destinations.

Self actions link to organization/profile and establishment management and expose Organization home. The latter uses preferred orientation, then headquarters, primary, another active location, locality, and regional fallback.
