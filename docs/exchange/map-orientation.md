# Exchange map orientation

Orientation precedence is explicit onboarding establishment, user preference, headquarters, primary, another active authorized establishment, released locality, then regional default.

Preferred orientation is stored on the person profile for the chosen organization. Changing it does not mutate primary/headquarters designations or any publication choice.

The first activation URL is explicit and therefore outranks an unrelated pre-organization saved camera. Later visits may restore the actor-bound remembered viewport. Organization home always requests the current server-authorized establishment and returns to close 3D.
